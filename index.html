AIMS-OS

Prototype Hub

Design prototypes for the next generation of agentic operations. Three cross-functional surfaces from Edgardo's model: Admin Studio authenticates, Data Studio maps the data flow, Agent Studio configures the tools agents can call.

Integrations · Admin Studio
Global activation and authentication. Catalog of 40 connectors, OAuth and API key, per-studio permissions, instance lifecycle, audit. The control plane for credentials and access.
Platform · Admin
Data Studio
Where data actually flows. Field mapping, table definitions, schema versions, templates. Cross-functional with Admin Studio — only shows integrations that are authenticated with Data Sync.
Data · Cross-functional
Agent Studio · Tools
What agents can actually do. Tools and pre-configured wrappers per integration — Edgardo's "Lego pieces for agents". Cross-functional with Admin Studio, shows only Tools capability (no Data Sync).
